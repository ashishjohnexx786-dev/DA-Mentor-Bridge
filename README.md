# DA Mentor Bridge

Course 2B companion app for the accelerated **Data Analyst → Data Engineer Bridge**.

## Identity
- Product: **DA Mentor Bridge**
- Course role: **Course 2B — DA-to-DE Bridge**
- Maintained branch: **main only**
- Interaction model: shared **DE Mentor 2026** study experience; the Bridge curriculum and its engineering-readiness Gates remain unchanged.

## Standard study route
Every lesson follows the same teacher-like route used across the four Mentor apps:
1. Understand the lesson goal.
2. Learn / read / watch the assigned material.
3. Follow one guided example.
4. Make a genuine independent attempt.
5. Open the protected review only after that attempt.
6. Complete a fresh retry without copying the review.
7. Explain the result aloud in your own words.
8. Mark Mastered only after the fresh retry and explanation are complete.

**Skip for now is not completion.** **I’m stuck** opens the repair route instead of granting mastery.

## Bridge integrity
- Module mastery still requires the required lesson evidence plus the Mini-Lab/Capstone and independent Gate where specified.
- Gate B/C remain protected retests and never auto-unlock as routine reviews.
- Course 3 readiness still requires the Bridge Final Gate and documented readiness evidence; lesson checkmarks alone are not enough.
- Manual **START STUDY / END STUDY** tracking uses the real start timestamp; there is no fixed Pomodoro countdown.
- Assigned videos and external professional references are preserved.

## Progress safety
The historical local-storage key `daMentorBridge.v2` remains the compatibility anchor. Legacy completion records are not silently promoted into current mastery without current evidence.

## Course-package routing
Inside the complete course package, file controls route to the matching `COURSE_MODULES/...` artifact. On standalone GitHub Pages, Mentor identifies/copies the exact course-package path when the artifact is not hosted beside the app.

## PWA / deployment
Static offline-ready PWA for GitHub Pages. The canonical app identity is **DA Mentor Bridge**.
