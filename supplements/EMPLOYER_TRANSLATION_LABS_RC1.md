# Employer Translation Labs RC1

These labs are additive. They do **not** replace, shorten, or change the 264-lesson Teaching RC2 core.

## Priority
1. **Databricks — strongly recommended after Stage 13** (6–8 focused hours). Translate existing Spark, Delta and Medallion skills into a real Databricks workspace.
2. **Snowflake — optional, target-job trigger after Stage 15** (3–4 hours).
3. **AWS — optional architecture translation after Stage 15** (3–5 hours).
4. **GCP — optional vocabulary/architecture translation** (about 2 hours).
5. **FastAPI — optional role-specific exposure** (1–2 hours).

Completion requires runnable evidence, not watching. Use the HTML hub for the exact sequence and official sources.

6. **NoSQL / MongoDB — optional employer-signal pack** (1–2 hours). Activate only when target roles ask for document/NoSQL storage.
7. **Apache Flink — optional streaming-framework translation** (about 2 hours). Activate only when target roles specifically ask for Flink.

## Why these stay optional
IBM/DataCamp-style programs commonly include NoSQL, while some modern DE bootcamps include Flink. Our mandatory route already teaches relational modeling plus Kafka and stateful/event-time streaming. These packs add vocabulary and one small proof without replacing the primary stack.
