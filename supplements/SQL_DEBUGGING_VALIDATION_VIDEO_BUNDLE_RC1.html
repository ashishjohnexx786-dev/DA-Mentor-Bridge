Purpose: make the debugging process visible without giving away the course exercise.

1. Systematic troubleshooting mindset — video

Microsoft Learn: Introduction to Performance Troubleshooting

Watch the short episode for the process: define the symptom, establish where to start, use evidence/tools, isolate the cause. Do not copy Azure-specific performance steps into a simple SQL-logic problem.

2. Wrong-result / duplicate validation — guided reference

Metabase Learn: Debugging duplicated data in SQL query results

Use this to check source duplicates, relationship cardinality, GROUP BY, and joins when row counts unexpectedly multiply.

3. Course proof — close both sources

  1. State the expected grain and row-count/control-total expectation.
  2. Run the smallest query that reproduces the wrong result.
  3. Check source uniqueness and join cardinality.
  4. Change one thing, rerun, compare evidence.
  5. Explain the root cause and why the fix is safe.
